# Project conventions

All user-facing UI text must be in English, including labels, buttons, help, status messages and errors. This applies to the world and every lab. Preserve the cultural spelling of generated character names.

When changing gameplay rules or balance values, update the relevant current gameplay documentation in the same change. Preserve historical measurement reports as records of their original rules.

Keep pull requests in draft until all required checks pass for the current head revision. Do not mark a PR ready or merge it while checks are failing, pending, or skipped because an earlier check failed. Report inherited failures explicitly; do not weaken or bypass validation to obtain green checks.
