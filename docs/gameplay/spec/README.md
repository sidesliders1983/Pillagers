# Pillagers — Canonical Gameplay Specification

This directory converts the current design baseline into stable, testable requirements.

Each mechanic uses: **ID**, **Status**, **User/System Story**, **Rules**, **Acceptance criteria**, and where needed **Open balance**.

Status:
- **Canonical** — behaviour is decided.
- **Prototype value** — mechanic is decided but numbers remain balancing parameters.
- **Open** — unresolved; implementation must not silently invent a canonical answer.

Files:
- 00 Core Principles
- 01 Time
- 02 Personas & Family
- 03 Work & Economy
- 04 Housing & Buildings
- 05 Cattle
- 06 World & Reconnaissance
- 07 Raiding & Combat
- 08 Weather
- 09 Player Actions

These requirements describe design intent, not implementation status.
