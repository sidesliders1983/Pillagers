# First steps — compatibility and current journey

The optional guide mechanics delivered in #263 are retained. Their current
player-facing layer is [The Founding Journey v0.1](FOUNDING-JOURNEY-V01.md), the
three-chapter follow-up in #270.

The four generic orientation goals are superseded by authored settlement,
discovery and conflict objectives. Existing version-1 firstSteps saves stay
readable; the bounded optional journey subrecord adds chapter choices and actual
UI acknowledgments. Derived canonical facts are reconstructed, not saved twice.

All ordinary New/Restart/Continue/import/load entries now stay paused through
readiness, story and either guidance choice until the actual Play control is
used. Only intentional internal view transfer has the documented fenced playback
exception. Continue/import never automatically reopen guidance.

The original implementation measurements remain unchanged in
[the #263 QA record](../qa/onboarding-263/report.md). Current predicates,
performance boundaries, skip/replay rules and acceptance questions are in the
Founding Journey contract and its separate QA record. No automatic merge/deploy.
