# Reference assets

User direction: from now on, no interpretations or procedural substitutes for supplied character reference assets. Hair, beards and other reference modules must use the supplied images through image-to-3D and optimization. Preserve source crops and provenance.

Cropping, background matting, extracting the intended module, removing disconnected remnants, aligning orientation and fitting to the existing fixed head/body are preparation steps. Preserve the generated silhouette. Profile-driven material colours and safe clearance adjustments remain supported.

A missing or unsuitable reference asset stays absent and is labelled pending. Do not silently substitute a different style or recreate the shape from primitives. Publish only the actual generated module after visual review of its orientation, extraction and fit.
