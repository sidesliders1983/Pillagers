# Environment art references

Original owner-provided images, copied without modification. [REF-A](REF-A.png) and [REF-B](REF-B.png) guide scenery composition, not new gameplay, snow, raids, weddings or UI implementation. [Reference manifest](references.json) records hashes, dimensions and crop coordinates.

[KayKit source lock](kaykit-source-lock.json) identifies the actual official 1.0 FREE archive, CC0 license, fourteen model roles, exact glTF/buffer paths and shared atlas hashes. These are sourced models, not generated substitutes. Tree_4_A/B/C are the three distinct authored conifers; Tree_1_B is a deciduous tree, not claimed as birch. Rock_2_H and Rock_1_Q are authored grouped outcrops; they are not distant fjord cliff modules. Grass_1_D and Grass_2_D are multi-blade clumps. Paid modular terrain is excluded.

Runtime conversions and contact-sheet evidence follow in #58. Source silhouettes are preserved; this file lock is not visual acceptance. Geometry reflections, distant cliffs and owner approval remain #59 gates.
