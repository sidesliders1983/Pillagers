# Hardware probes and interrupted initial pass

The CPU-only smoke test (seed 32, narrative seed 7, opening) returned an accepted catalogue selection in 86,075 ms: 1,824 prompt tokens and 20 completion tokens. llama.cpp reported 80,774 ms prompt processing and 5,004 ms decoding. This is one feasibility probe, not a complete CPU benchmark or a paired CPU/GPU speedup claim. Its implicit min_p was 0.05 with top_k=1; final comparison pins min_p=0 explicitly.

The first GPU multi-campaign pass was stopped before completing the cohort. Its raw completed outcomes and two-second resource samples remain in `candidate-B-initial-memory-probe.jsonl` and `resource-B-initial-memory-probe.jsonl`. No incomplete pass is presented as sixty completed requests. GPU process private/committed memory grew as the server stored prompt cache entries; the default RAM cache limit was 8,192 MiB. Observed process peak working set reached 5,673,873,408 bytes and peak committed memory 8,272,949,248 bytes. Free disk briefly approached 87 MB while Windows expanded paging, then recovered after the experiment processes stopped. No user assets or unrelated server were removed; only regenerated build output and the uncompressed copy of preserved gzip corpus were removed.

The corrected comparison disables RAM prompt cache and context checkpoints, and requests --no-cache-prompt through the CLI (all accepted main-cohort B/C responses report cached_tokens=0; slot-selection log messages alone do not establish reuse), retains one slot, and preserves the same frozen corpus. Both candidate runs use the pinned corrected configuration. The interrupted probe is retained separately, including its context-budget fallbacks. Its earliest HTTP failure bodies were not captured by the adapter; the current adapter preserves raw HTTP error bodies, tested through the public interface. Do not treat a diagnostic replay as the original transport response.

No paid service or external inference occurred. The private raw runtime is not a LAN endpoint, and the developer investigation is not enabled in player routes.
