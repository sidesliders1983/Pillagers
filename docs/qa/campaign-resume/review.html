Return to your settlement

Issue #161. Returning keeps the campaign paused. A normal return retains the live scene; a real reload restores the saved island without a new landing animation.

Open the game with recovery diagnostics

Physical Safari review

  1. Open your existing campaign. Use Menu → Save locally as a backup. Note the season, year, resources and selected resident.
  2. Start the clock, leave Safari for 10 seconds, then return. Expect the same island and camera, a paused clock and no time gained while away.
  3. Repeat after 2 minutes in another app, then after a longer interval when practical. Safari may preserve the scene or genuinely reload the document. A cold return should say “Returning to your settlement…” and remain responsive.
  4. Use Start to continue, and confirm selection, camera gestures, people and resource totals still work.
  5. Open Menu → Download recovery diagnostics. Report the interval tested and whether the return was immediate, showed the resume screen, or became stuck. The trace distinguishes cached return from cold navigation.
