Suggested checks

  1. Select a tent → Manage work → choose a work plan → review and confirm. Farming is one option among ten occupations.
  2. In the funded scenario: select a tent → Manage work → Set up farmyard → Confirm setup. The default proposal includes three unassigned cattle.
  3. Select residents and inspect traits, productivity, occupation fit, family, heritage and personal history.
  4. Select a permanent home. Change specialization using the occupation icons; review the next upgrade’s bonus, cost and upkeep directly on the home card. Residents keep their occupations.
  5. Use the exploration scenario for expeditions. Other scenarios retain their original discovery settings. Add or remove group members inside Expeditions, regardless of the selected object.
  6. Open Settlement, Expeditions, Clan Book and Attention; try save/load and a second seed.
  7. Pan with left drag, rotate with right drag and zoom with the wheel. Start/Pause controls the actual simulation.
  8. Use Menu → Camera views & controls → View highlands to inspect the rock and permanent summit snow. View settlement returns to the village.

These are existing gameplay systems with a new interface. Future cultural gatherings, apprentice recruitment, carts and clan trading are outside this build. Terrain remains the current game-scale geography.
