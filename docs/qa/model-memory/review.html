Smaller model textures

Twelve existing housing, tent and campfire models: 140 → 35 MiB of RGBA8 image pixels. Geometry, UVs, animation and material bindings are identical. These are calculated image budgets, not measured total browser memory.

The ordinary game is unchanged. The candidate requires compactModels=1 and the existing Low quality setting at scene creation. Use one game tab at a time and reload fully between comparisons. Both versions must use the same campaign and Low setting. Full scene appearance, sustained memory and the reported browser crash remain to be checked on a physical device.
