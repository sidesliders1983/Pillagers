FJORDSIDE / DESKTOP UI STUDY

Housing first. Work by choice.

Three layouts for a household with a hunter and a fisher. Building their home keeps both occupations.

Open interactive study →
2 clicksSelect tent → Build house. Current work, specialization and cattle assignments stay unchanged.
3 clicksSelect resident → Change work → occupation. All ten existing occupations are represented.
4–5 clicksOptional farmyard setup, including the household work menu; five if choosing another farmer.

Compare the optional combined farmyard task: Layout A · Layout B · Layout C. This task proposes a farmer and cattle assignments only after the player chooses it. Building housing alone does not assign an occupation. A household that already has a farmer gains the existing Farmyard function when housed, with no automatic cattle assignment.

Measured at 1440 × 900. Coverage counts the union of UI rectangles, including translucent panels. These are prototype input counts, not proof that the current game already provides these shortcuts. No preference or winning layout has been selected.

The funded farmyard scenario is derived from the original five-Materials fixture using the existing longship salvage command (+20 Materials). This prepares the fixture; farmyard setup never silently salvages a ship. The original insufficient-Materials scenario is also available. Actions change only local review state.

Each layout uses the same actual world capture. Building a house in the prototype changes its summary and resource preview; the captured world does not animate or rebuild. No FPS, simulation-performance or visual-world improvement is claimed.
